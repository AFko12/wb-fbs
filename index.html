Откуда куда возить

Медиана пути «заказ → вручение». Сравнивать склады между собой можно только внутри одного столбца: у складов разная география, и разница вдвое чаще означает «возит дальше», а не «работает хуже». Наведите на значение — число заказов. Лучшее значение в столбце выделено жирным.

Этапы пути по складам

Разбивка времени: сколько собираем и сдаём мы, сколько СЦ принимает после сдачи (приёмка/сортировка) и сколько заказ едет к покупателю после приёмки. Медианы по заказам выбранного периода; наведите — число заказов с этим этапом.
Данных об этапах пока нет — они появятся после первого обновления с токеном, у которого есть категория «Маркетплейс» (даём доступ к поставкам FBS).

Динамика по неделям

Медиана времени доставки по неделям (по дате заказа), в днях — по выбранному складу и периоду.

Выкуп и отказы по округам

Выкуп — доля заказов, доведённых до продажи без возврата. Отказы — отмены и возвраты. Считается только по заказам старше 7 дней: свежие ещё в пути, и доля по ним была бы неправдой.
